# RVN — НИР «Равенство»: модуль первичной обработки сигналов судовой РЛС

НИР «Формирование облика программно-аппаратных средств первичной обработки сигналов судовой радиолокационной станции S- и X-диапазонов» для АО «Равенство» (договор № ОПР-002Н/8-2д от 01.04.2026, ДС № 1 от 18.09.2026). Исполнитель — ОКБ РЭС ГУАП.

В репозитории лежат отчёт о НИР, программа и методика испытаний с протоколами, конструкторская документация на модуль ПОС, плату ПОС, рабочее место и кабели, а также исходные документы (ТЗ, письма, закупки).
