# Границы эскиза

Рассматривается один антенный пост и одно мостиковое рабочее место (П). Для двухпостового исполнения потребуются отдельные решения по распределению потоков, выбору источника и резервированию.

Коммерческие сканеры служат аналогами организации монтажа и внешнего обмена. Возможность подключить их внутренние тракты к модулю ПОС по опубликованным данным не установлена. Для закупки смежного приёмопередатчика требуется согласованный документ на интерфейс.

Децимальное обозначение Э2, марки кабелей и классы исполнения оборудования подлежат согласованию. Обозначения в реестрах служат для навигации по эскизу.
