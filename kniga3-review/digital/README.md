# Воспроизведение цифровых исследований

Запустить `python3 calculate.py` из этого каталога. Скрипт использует стандартную библиотеку Python 3 и перезаписывает CSV. Точка означает десятичный разделитель. Источники, ограничения и выводы приведены в `study.md`.

`gaussian_clutter.csv` содержит модельную оценку для входного гауссова доплеровского спектра и двух вариантов длины БПФ. Приведённая стандартная ошибка относится к оценке среднего остатка по независимым синтетическим пачкам. Она не характеризует погрешность рабочего места.
