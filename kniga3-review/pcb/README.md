# Технологическое исследование платы АРБМ.468157.011

`report.md` содержит результаты для включения в Книгу 3 и ограничения исходных данных.

Исходные файлы Gerber и проектный стек находятся в каталоге `АРБМ.468332.022 Модуль ПОС/АРБМ.468157.011 - Плата ПОС/POS26 gerbers/Gerbers` репозитория RVN, срез `2d8bd10eb57b32262a08e4979e4d687d8ffdbe52`. Хеши файлов приведены в `outputs/input_sha256.txt`. Изготовитель и материалы конкретной партии по этому комплекту не идентифицируются.

Для повторения расчётов использовать Python 3.12. После установки зависимостей командой `python -m pip install -r requirements.txt` выполнить из каталога исследования:

```sh
python copper_coverage.py '/путь/к/RVN/АРБМ.468332.022 Модуль ПОС/АРБМ.468157.011 - Плата ПОС/POS26 gerbers/Gerbers' --output outputs
python crosscheck_coverage.py '/путь/к/RVN/АРБМ.468332.022 Модуль ПОС/АРБМ.468157.011 - Плата ПОС/POS26 gerbers/Gerbers' --output outputs/copper_crosscheck.csv
python plot_coverage.py
python laminate_compare.py --output outputs/laminate_compare.csv
```

Расчёт по Gerber использует прямоугольный контур по осевым линиям GM1, положительную полярность и порядок операций Gerber. Площадь определяется числом медных пикселей, делённым на квадрат разрешения в пикселях/мм. Сетка 4 × 4 привязана к координатам GM1. Сверловка и реальные допуски травления не входят в расчёт. Независимая проверка растеризации использует Gerbonara и CairoSVG при 40 пикселях/мм с весом градаций серого на границах штрихов. Для CairoSVG нужна системная библиотека Cairo. Входные числа для сравнения ламинатов приведены в `laminate_inputs.csv`. Значения для идеальной TEM-линии характеризуют расчётную чувствительность к материалу при неизменном поперечном сечении.

## Обработка купонов по поручению 14 протокола от 13.11.2026

`coupon_reduction.py ring` принимает длину средней линии кольца в мм, резонансную частоту в ГГц и номер моды. Результат относится к эффективной фазовой проницаемости на этой частоте. Скрипт не учитывает сдвиг моды из-за связи с возбуждающей линией.

`coupon_reduction.py line line.csv --length-difference-mm ΔL` принимает данные двух линий с совпадающими частотами и одинаковыми переходами. Заголовки CSV приведены ниже. Входной диапазон выбирают по задаче и качеству калибровки. Частотный шаг должен обеспечивать изменение истинной разности фаз между соседними точками меньше π. Берут данные после приведения плоскостей отсчёта и исключения участков с недостаточным отношением сигнал/шум и сильными отражениями. Результат — групповая задержка по аппроксимации фазы одной прямой во входном диапазоне. Среднеквадратический остаток характеризует согласие с этим допущением. Неопределённость измерения оценивают отдельно.

```text
frequency_hz,s21_short_real,s21_short_imag,s21_long_real,s21_long_imag
```

Скрипт проверен на аналитических данных для заданных Dk_eff и задержки. Измерений с купонов платы ПОС к протоколу не приложено.
