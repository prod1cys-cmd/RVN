## Воспроизведение

Для извлечения издания и вложения служит [extract.py](extract.py). Первый аргумент — файл AD8367 Rev. A в PDF, второй — KSZ9893R DS00002420F в PDF, третий — приложенная Книга 2, часть 3 в DOCX. Скрипт сверяет SHA-256 документов и сохраняет рисунки рядом со скриптом. Нужен пакет PyMuPDF.
