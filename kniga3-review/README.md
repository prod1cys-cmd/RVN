Для повторения расчётов см. указания в каталогах исследований. Таблицы и графики получены из сохранённых входных данных и скриптов. Параметрические результаты описывают только указанные сценарии. Заполненные протоколы испытаний в изученном комплекте отсутствуют.

Из корня репозитория проверка итоговой пары выполняется после установки `python-docx` и `pymupdf`:

```sh
book='Отчетная документация/АРБМ.468332.022ПЗ Модуль ПОС Книга 3'
python kniga3-review/verification/audit.py "$book.docx" "$book.pdf"
python kniga3-review/verification/check_protocol_forms.py "Отчетная документация/Протоколы_испытаний_К01-К22"
```

Проверка по И2 v2 и протоколу от 13.11.2026 включена в матрицу технического совещания. Расчёты по квантованию, плоскостям отсчёта AD8367 и наложению спектров описаны в [дополнении по аналоговому тракту](analog/i2_protocol_reconciliation.md). Подлинные файлы однозначно идентифицируются по [контрольным суммам](verification/Приложенные_источники.md).
