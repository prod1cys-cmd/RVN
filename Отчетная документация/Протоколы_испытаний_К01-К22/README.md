# Протоколы испытаний К-01…К-22

Бланки протоколов лабораторных испытаний функциональных макетов модуля ПОС по программе и методике АРБМ.468332.022ПМ. Один протокол — один вид контроля. К-21 и К-22 проводятся только для макета 2, остальные — для обоих макетов.

| Протокол | Вид контроля (начало названия) | Пункт ПМ |
|---|---|---|
| К-01 | работоспособности каналов приёма и | 9.1 |
| К-02 | полосы пропускания тракта для | 9.2 |
| К-03 | собственных шумов и динамического | 9.3 |
| К-04 | переходного затухания между каналами | 9.4 |
| К-05 | формирования запуска модулятора | 9.5 |
| К-06 | формирования защитного импульса приёмника | 9.6 |
| К-07 | привязки к моменту излучения | 9.7 |
| К-08 | приёма углового положения антенны | 9.8 |
| К-09 | режимов работы РЛС | 9.9 |
| К-10 | амплитудной характеристики детектирования | 9.10 |
| К-11 | временной автоматической регулировки усиления | 9.11 |
| К-12 | подавления помех | 9.12 |
| К-13 | некогерентного накопления | 9.13 |
| К-14 | адаптивного порогового обнаружения | 9.14 |
| К-15 | формирования первичных отметок | 9.15 |
| К-16 | циклограммы обработки и времени | 9.16 |
| К-17 | канала Ethernet и формата | 9.17 |
| К-18 | интерфейсов CAN RS-422 RS-232 | 9.18 |
| К-19 | управляемости макета | 9.19 |
| К-20 | соответствия результатов обработки математической | 9.20 |
| К-21 | квазикогерентной обработки с фазированием | 9.21 |
| К-22 | выдачи необработанного оцифрованного сигнала | 9.22 |

Перед контролем в протокол заносится расчётное значение параметра и его источник (п. 3.4, 3.7 ПМ). Заполненные протоколы — экспериментальные данные НИР; результаты используются в книге 3 (раздел о макетах) как подтверждение решений.
