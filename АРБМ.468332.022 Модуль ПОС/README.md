# АРБМ.468332.022 Модуль ПОС

Конструкторская документация на модуль первичной обработки сигналов и средства его испытаний.

| Файл / папка | Содержание |
|---|---|
| АРБМ.468332.022Э2 Модуль ПОС (.cdw, .pdf) | Схема электрическая функциональная модуля (облик для ОКР: плата обработки, память программируемой логики 4 ГБ, интерфейсы, питание 12 В) |
| АРБМ.468332.022Э4 - Модуль ПОС (.cdw, .pdf) | Схема электрическая соединений макета: плата ПОС, вентиляторы, карта microSD, розетки XS1–XS6 («ТО», «CAN», «BAZALT и HMC», «IO 1V8», «IO 3V3 STM», «IO 3V3 ZYNQ») |
| [АРБМ.468157.011 - Плата ПОС](АРБМ.468157.011%20-%20Плата%20ПОС/) | Плата ПОС — основа обоих функциональных макетов |
| [АРБМ.468915.018 Рабочее место](АРБМ.468915.018%20Рабочее%20место/) | Рабочее место для испытаний и кабели |

Важно: функциональная схема модуля (Э2) показывает облик изделия; макеты собраны на плате ПОС АРБМ.468157.011, в которой нет памяти DDR3 программируемой логики (только 1 ГБ у процессорной подсистемы). Отличия макетов от модуля перечислены в книге 3.
