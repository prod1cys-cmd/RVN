Генератор КД на кабели К4, К5, К6, К10, К14 (рабочее место АРБМ.468915.018)

Установка:  pip install matplotlib ezdxf
Запуск:     python kd_cables.py ../Результат

Что меняется где:
  kd_data.py   — все данные: децимальные номера (NUM), длины, составы,
                 таблицы соединений, технические требования, расчёт материалов.
  eskd.py      — рамка, основные надписи (ф.1, 2, 2а), бланк спецификации ГОСТ 2.106.
  kd_cables.py — графика сборочных чертежей и вывод PDF/DXF/CSV/MD.

Фамилии в основных надписях — словарь PEOPLE в kd_cables.py.
DXF открываются в КОМПАС-3D (Файл → Открыть, тип DXF), линии разнесены по слоям
«ОСНОВНАЯ» (0,7) и «ТОНКАЯ» (0,35).
