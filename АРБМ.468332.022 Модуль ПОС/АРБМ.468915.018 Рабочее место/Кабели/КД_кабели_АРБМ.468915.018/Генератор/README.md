# Генератор КД на кабели

Скрипты строят сборочные чертежи и спецификации кабелей К4, К5, К6, К10, К14 по ЕСКД.

```
pip install matplotlib ezdxf
python kd_cables.py ../Результат
```

| Файл | Назначение |
|---|---|
| kd_data.py | Данные: децимальные номера, длины, составы, таблицы соединений, технические требования |
| eskd.py | Рамка и основные надписи (формы 1, 2, 2а), бланк спецификации ГОСТ 2.106 |
| kd_cables.py | Графика чертежей, вывод PDF/DXF/CSV/MD; фамилии в основных надписях — словарь PEOPLE |
| README.txt | Исходная инструкция |
