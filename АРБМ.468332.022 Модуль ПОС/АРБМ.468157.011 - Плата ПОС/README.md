# АРБМ.468157.011 Плата ПОС

Печатная плата обработки на СнК Zynq-7000 XC7Z030-1FFG676I с АЦП/ЦАП К5119ПВ1Я, синтезатором HMC7044, усилителями ПЧ AD8367, памятью DDR3 1 ГБ, флеш-памятью 2 × MT25QU02G, микроконтроллером STM32H745, коммутатором Ethernet KSZ9893 и преобразователем USB FT4232HL. На ней собраны функциональные макеты 1 и 2.
