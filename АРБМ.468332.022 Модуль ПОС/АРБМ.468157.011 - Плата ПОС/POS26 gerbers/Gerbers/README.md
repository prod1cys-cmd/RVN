# Gerbers — плата ПОС

Две версии комплекта: `POS26_12.*` и `POS26_13.*` (актуальная — 13; заводской номер и дата маркируются на слое `POS26_13.GTO`).

| Расширение | Слой |
|---|---|
| .GTL / .GBL | Верхний / нижний проводящий слой |
| .GTO / .GBO | Маркировка верх / низ |
| .GTS / .GBS | Паяльная маска верх / низ |
| .GTP / .GBP | Паста верх / низ |
| .GM1 | Контур платы |
| POS26_stack.csv | Стек: 8 слоёв, препрег PP-006 (Dk 4,1, Tg 180 °C), сердечник FR-4 0,5 мм |
| Бланк заказа на ПОС.xls | Заказ: 5 плат, 233,35 × 160 мм, FR-4 HiTg, 1,6 мм, иммерсионное золото, контроль импеданса 100 Ом (0,1/0,1 мм) и 50 Ом (0,13 мм) |
