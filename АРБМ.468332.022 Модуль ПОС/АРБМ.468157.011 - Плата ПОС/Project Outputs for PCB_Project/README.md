# Выходные файлы проекта платы (Altium Designer)

| Файл | Содержание |
|---|---|
| BOM.xlsx | Перечень компонентов (по нему ведётся `Статус_закупки.xlsx`) |
| PCB_Project.xlsx | Выгрузка компонентов проекта |
| PCB_Project.NET, Zynq.NET, PCB_Project.nsx | Списки соединений (netlist) |
| Net Status - PCB1 (.html, .txt) | Состояние разводки цепей |
| Status Report.Txt | Отчёт проверки проекта |
